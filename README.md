# website-27

Portfolio site for Madebysatyam. Next.js App Router + React.

## Setup

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000).

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Plain CSS (no Tailwind)

Agent skills live in `.agents/skills/` (Emil Kowalski animation/UI skills).
